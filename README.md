# Hot-Bento-Production
RPG Turn-based combat game.


*SET-UP DEL PROGETTO*

Per caricare file di dimensioni maggiori di 100 MB (dimensione massima consentita da Github) è necessario caricarli tramite CMD e usare Github Desktop, l'applicazione apposita di Github. è necessario usare entrambe per caricare simili file correttamente.
Il CMD in windows può essere aperto cercando la parola chiave CMD nella barra di "Cerca" di windows o con click del tasto destro del mouse in una folder qualsiasi di esplorare risorse, compreso il desktop.
Nel CMD bisogna inserire il comando: $ git lfs track "nomefile.formatofile" (esempio "foto.png"). Attenzione, ricordare di mettere gli apicetti per confinare il nome e il formato del file da caricare.
Dopo avere eseguito il comando da CMD, è necessario compiere l'azione "Push" tramite Github Desltop del file ".gitattributes" situato nella cartella del progetto di git.
Fatto ciò, basta fare un "drag&drop" del file interessato (file più grande di 100 MB) dalla folder dentro Github Desktop, facendo attenzione di selezionare il progetto Hot-Bento-Production. Una volta che il file appare nell'applicazione, si può procedere con l'azione di "Push" per completare il caricamento sul cloud.
